# Guia do Admin

O painel administrativo sera implementado a partir da Fase 2.

## Regras da fundacao

- O usuario admin inicial vem de `ADMIN_EMAIL` e `ADMIN_PASSWORD`.
- A senha deve ter pelo menos 12 caracteres.
- A senha sera salva apenas como hash.
- Rotas administrativas reais devem ser protegidas antes de serem criadas.
- Alteracoes importantes devem gerar auditoria.
